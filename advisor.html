PDAEH Advisor

Esta interfaz no simula ni anticipa una respuesta. Estructura el contexto y lo prepara para que el skill PDAEH Advisor instalado realice el diagnóstico mediante razonamiento del agente y su base de conocimiento.

Ejecución real: la respuesta se produce en Codex, Claude Code, Gemini CLI u otro agente compatible donde el skill esté instalado. GitHub Pages no puede ejecutar procesos locales ni acceder a sus credenciales.

Preparar el caso organizacional

Sin respuesta determinista

Ejecutar en el agente instalado

  1. Abra una sesión nueva del agente donde instaló el skill.
  2. Complete el contexto organizacional en esta página.
  3. Pulse Copiar solicitud completa y péguela como un único mensaje: incluye la invocación $pdaeh-advisor y el caso estructurado.
  4. Continúe la conversación: el agente puede pedir información faltante, contrastar restricciones y adaptar la hoja de ruta.
$pdaeh-advisor

Si todavía no está instalado:

curl -fsSL https://corozco-personal.github.io/pdaeh-tesis-doctoral/install.sh | bash -s -- --global

La variación de la respuesta depende del contexto suministrado, del modelo y del diálogo. No se selecciona una plantilla fija por tamaño de empresa.
